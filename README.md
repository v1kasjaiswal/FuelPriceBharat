# <div align="center">**🚀Fuel Price Bharat - Kotlin Android App🚀**</div>

#### <div align="center">**Developed using Kotlin - XML Layout**

</div>

This is one of my first Kotlin Android XML Layout projects⛽. It is a simple Fuel Price application that is designed to provide fuel prices for Petrol, Diesel, CNG, LPG based on the selected city using RapidAPI. This application features a smooth XML based UI design with two primary screens, a splash screen✨ and a fuel price details🗒️ screen that displays up-to-date fuel rates. This project strengthened my skills in Kotlin, Android XML, API integration, and UI/UX design, helping me build a more engaging and efficient mobile application📱.

PS - This was one of my first apps developed in 2023. It showcases my foundational skills in Kotlin, Android development as well as my ability to learn continuously by building real-world applications🔥

### **// Features⚡**

- **Splash Screen**: A beautiful splash screen with a logo and animation.
- **XML Layout**: The app is built using XML layouts for a clean and efficient UI design.
- **API Integration**: Fetches real-time fuel prices using the RapidAPI Fuel Price Rate API.
- **City Selection**: Users can select their city from a dropdown list to get the fuel prices for that city.
- **Fuel Price Details**: Displays the latest fuel prices for Petrol, Diesel, CNG, and LPG based on the selected city.
- **Material Design**: The app follows Material Design guidelines for a modern and user-friendly interface.
- **Error Handling**: Proper error handling for network requests and API responses.

---

### **// XML Layout Components 🪨**

- **TextView**: Displays text on the screen, such as fuel prices and city names.
- **ImageView**: Displays images, such as the app logo and fuel icons.
- **Button**: A clickable button that allows users to fetch fuel prices for the selected city.
- **Spinner**: A dropdown menu that allows users to select their city from a list.
- **LottieAnimationView**: Displays animations using Lottie for a more engaging user experience.
- **CardView**: A container for displaying fuel price details in a card format.
- **ConstraintLayout**: A flexible layout that allows you to create complex layouts with a flat view hierarchy.

---

### **// Libraries and Dependencies 🤖**
- **Kotlin**: The primary programming language used for Android development.
- **XML**: The markup language used for designing the UI layouts in Android.
- **ConstraintLayout**: ConstraintLayout allows you to create complex layouts with a flat view hierarchy.
- **OkHttp**: OkHttp is an HTTP client for Android handling network requests and responses.
- **Lottie**: Lottie is a library for rendering animations in Android applications.
- **JSONObject**: A class for parsing responses from APIs in JSON format.

### **// Installation 📲**

- Clone the repository using the following command:

  ```bash
  // Clone the repository
  git clone https://github.com/v1kasjaiswal/FuelPriceBharat.git

  // Change the directory
  cd FuelPriceBharat

  // Go to res/values/strings.xml
  // Get the API key and replace it with the API key
  <resources>
      <string name="rapidapi_key">REPLACE_WITH_YOUR_OWN_API_KEY</string>
  </resources>
  ```

- Open the project in Android Studio and build the project.
- Run the project on an emulator or physical device.
